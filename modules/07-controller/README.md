# 模块 07：控制层（AimThread / PID / 控制器）

## 它是什么？

控制层是"瞄准大脑"：根据目标偏差，算出平滑、可控的移动指令。

## 它干什么？

1. **PID 控制**：根据偏差（error）计算输出
   - P（比例）：偏差越大，动得越多
   - I（积分）：消除长期的小偏差
   - D（微分）：抑制抖动，让移动更平滑
2. **平滑/限速**：不让鼠标瞬移（太快会被发现/失控）
3. **死区**：偏差太小时不动（避免抖动）
4. **热键门控**：只有按下指定按键才进入瞄准模式
5. **预测**：根据目标运动趋势，预判目标位置

## 输入是什么？

- 目标偏差（error_x / error_y，来自模块 06）
- 热键状态（是否按下瞄准键）

## 输出是什么？

- 鼠标移动指令（dx, dy）：控制层决定"动多少"
- 状态指标：aim_active（瞄准中）、mouse_dx/dy

## 谁调用它？

- `CoreRuntime` 启动的 `AimThread`（独立线程，每帧循环）

## 它不能干什么？

- 不能物理移动鼠标（那是模块 08 做注入）
- 不能在没有授权时输出（output_enabled 必须为 false 时保持静默）

## 修改它会影响什么？

- 影响跟手感和稳定性 → PID 参数是手感核心
- 当前所有 PID 相关参数都已调优验证，**禁止为了测试覆盖生产参数**
