# 模块 06：坐标层（CoordinateTransform）

## 它是什么？

坐标层负责"换算"：把目标在画面里的位置，换算成鼠标该动多少。

## 它干什么？

1. **计算偏差**：目标点离屏幕中心差多少像素（error_x, error_y）
2. **坐标变换**：考虑各种缩放、轴比例、视野（FOV）因素
3. **输出位移**：得出鼠标应该移动的方向和大小

## 输入是什么？

- 目标位置（来自模块 05，原图坐标）
- 屏幕中心（参考点）

## 输出是什么？

- 偏差量（error_x / error_y）：目标偏离中心多少像素
- 供控制层（模块 07）使用的误差输入

## 谁调用它？

- `AimThread`（瞄准线程：选目标 → 算偏差 → 控制输出）

## 它不能干什么？

- 不能移动鼠标（那是模块 08 的事）
- 不能决定"打不打"（那是热键门控的事）

## 修改它会影响什么？

- 影响瞄准准确度 → 偏差换算错 = 鼠标打偏
- **已通过坐标闭环验证（5 组坐标误差 0.00），禁止随意改动**
