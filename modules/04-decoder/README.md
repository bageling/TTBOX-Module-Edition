# 模块 04：检测解码层（Decoder / DecodeNMS）

## 它是什么？

解码层把 AI 模型输出的"一堆看不懂的数字"，翻译成"人看得懂的检测框"。

## 它干什么？

1. **解码**：把模型的原始输出（坐标+类别分数）变成候选框
2. **过滤**：低于置信度（confidence）阈值的框扔掉
3. **去重（NMS）**：同一个目标被框了好几次，只保留最好的那个
   - NMS = Non-Maximum Suppression（非极大值抑制），就是"多个框留一个"
4. **坐标映射**：把模型小图里的坐标，换算回 2560×1440 原图坐标

## 什么是 Detection（检测结果）？

Detection = 一个检测框，包含：
- class_id（类别编号，如 0=人、2=汽车、5=公交车）
- score（置信度，0~1，越接近 1 越有把握）
- x1,y1,x2,y2（框的左上角和右下角坐标，单位是原图像素）

## 什么是 ModelAdapter（模型适配器）？

不同的模型输出格式不一样：
- yolo261n：单输出 `[1,84,8400]`（1 个输出，8400 个候选）
- jwdl_sjzv11：6 个输出（3 尺度 × 回归/分类，DFL 格式）

ModelAdapter 根据模型的输出结构自动选择解码方式，不需要人手动配置。

## 输入是什么？

- RKNN 原始输出张量（模块 03 的产物）
- 模型信息（输入尺寸、输出结构、量化参数）

## 输出是什么？

`DetectionBox` / `Detection` 列表（检测框），坐标已在原图 2560×1440 坐标系。

## 谁调用它？

- `WorkerPool` 的 Worker（实时链路，每帧都解）
- `Detector`（统一边界）
- `imgdetect` 工具（单张图片的检测，用于验证）

## 它不能干什么？

- 不能推理（那是模块 03）
- 不能选目标（那是模块 05）
- 不能移动鼠标（那是模块 08）

## 修改它会影响什么？

- 影响检测框的准确度、数量、置信度
- 解码格式与模型不匹配 = 检不出东西
- **已通过坐标闭环验证（误差 0.00），禁止随意改动算法**（见 docs/验证/）
