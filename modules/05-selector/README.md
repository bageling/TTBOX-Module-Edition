# 模块 05：目标选择层（TargetSelector）

## 它是什么？

目标选择层负责回答一个问题："画面里有好几个目标，我先打哪个？"

## 它干什么？

当检测层给出多个 Detection（例如 3 个敌人），选择层按规则挑出**唯一一个**要跟踪的目标：

- 优先选择距离屏幕中心最近的目标（常见规则）
- 或按配置选择特定类别（例如只打 class 0）
- 连续多帧稳定才切换目标（防止乱跳）
- 目标锁定后提供稳定的目标点（框中心或按配置偏移）

## 输入是什么？

- 检测结果列表（多个 Detection，来自模块 04）
- 屏幕中心参考点

## 输出是什么？

- 选中的目标（Target）：类别、位置、大小、目标点坐标

## 谁调用它？

- `AimThread`（瞄准线程，每帧选择目标后计算控制量）

## 它不能干什么？

- 不能识别目标（那是模块 03/04）
- 不能算移动量（那是模块 07）
- 不能移动鼠标（那是模块 08）

## 修改它会影响什么？

- 影响"打谁"的决策 → 直接影响瞄准手感
- 目标选择规则是手感核心之一，改动需谨慎验证

## 关键文件

| 文件 | 作用 |
|---|---|
| `core/src/mouse/TargetSelector.cpp/.hpp` | 目标选择器（选最近/按类别的目标） |
| `core/src/mouse/AimTracker.cpp/.hpp` | 目标跟踪（连续帧稳定性） |
| `core/src/mouse/AimPointProfile.cpp/.hpp` | 瞄准点配置（框中心/偏移） |
