# TTBOX阶段1代码瘦身清理清单

> 工作区：`C:/Users/Administrator/Desktop/TTBOX`
> 原则：只清理重复、历史、明确非生产内容；不进入 Preprocess、Detector、Coordinate 重构。
> 基线：当前目录无 `.git`，因此以文件清单、字节级重复、全仓库文本引用、CMake/服务/部署脚本为证据。

## 清理决策

| 对象 | 基线引用/证据 | 决策 | 理由 |
|---|---:|---|---|
| `yu-backend/yu-core-src/core/` | 该路径仅在 3 份架构文档出现；目录内源码与根 `core` 大量字节级重复；未被 CMake、服务或脚本路径调用 | 删除 | 历史 Core 副本，不是运行/构建/测试输入 |
| `core/tools/web/ttbox-infer.service` | 被 `core/tools/web/a10_deploy.sh` 复制并随后 disable；同时被 `core/tools/web/ttbox_web.py` 多处控制/状态查询 | 保留 | 仍存在真实 Web 管理引用；直接归档会破坏现有管理面，本阶段不改变生产逻辑 |
| `core/tools/web/ttbox-infer.sh` | 被 `ttbox-infer.service` 与 `core/tools/web/ttbox_web.py` 引用；依赖 `test_worker_hw`、`active_model.txt`、`infer.json` | 保留 | 仍是旧推理管理路径的实际脚本；下一阶段先迁移引用再归档 |
| `core/tools/hardware_runner_main.cpp` | 被根 `core/CMakeLists.txt` 注册为独立硬件工具；有 `test_hardware_runner` 测试 | 保留 | 测试/验收工具，非生产入口 |
| `runtime/HardwareRunner.*` | 被 `hardware_runner_main.cpp` 与硬件测试使用 | 保留 | 测试/验收生命周期实现 |
| HID/Output 实现 | `OutputBackend`、`AiboxHidOutput`、`FifoHidOutput` 等被 Application、Runtime、HardwareRunner、测试或 CMake 引用 | 保留 | 当前阶段不重新设计、不删除有调用方实现 |
| `model_label`、`model_input_*`、`RuntimeProfile.model_id`、`active.json`、`active_model.txt`、`infer.json` | 存在实际读取链或部署/测试引用 | 保留并记录 | 本阶段不改配置系统；下一阶段统一 |
| Worker CPU Direct/RGA/ROI/resize | 位于当前 Worker 实际处理路径 | 保留 | 本阶段不做 Preprocess 重构 |
| Web/Gateway/IPC | 服务、脚本和测试存在真实引用 | 保留 | 管理面不删除；只清理明确废弃路径 |

## 执行顺序

1. 删除历史重复 Core 副本。
2. 归档旧 `ttbox-infer.service` 与 `ttbox-infer.sh`。
3. 更新部署脚本，移除对已归档旧推理服务文件的复制与 disable 操作。
4. 全仓库检查删除路径、CMake、服务和部署引用。
5. Release 构建、CTest、入口与生产链检查。
6. 生成阶段1完整报告。
