# 小白使用说明

> 本文档写给完全不懂代码的用户。看完这篇，你就知道 TTBOX 是什么、怎么用、安全边界在哪。

## 一、TTBOX 是什么？

TTBOX 是一台小盒子（OrangePi 5 Plus 开发板），
它通过 **HDMI 线"看"你电脑屏幕上的画面**，用 **AI 识别画面里的目标**。

```
电脑画面 ──HDMI线──▶ 盒子（RK3588）
                       │
                       ▼
              AI 分析画面（每秒 39~43 帧）
                       │
                       ▼
              "画面里有什么？目标在哪？"
                       │
                       ▼
              目标选择 → 坐标 → 控制器
                       │
                       ▼
              MouseCommand（鼠标命令）
                       │
              【本阶段停止，不真正动鼠标】
```

## 二、两条线路（重要！）

| 线路 | 作用 | 类比 |
|---|---|---|
| HDMI（视频链路） | 画面从电脑 → 盒子 | 盒子的"眼睛" |
| USB（控制链路） | 指令从盒子 → 电脑（未来） | 盒子的"手" |

**USB 不是视频链路！** 画面只走 HDMI。USB 是盒子与电脑的独立连接（伪装鼠标键盘用）。

## 三、盒子上有什么接口？

- HDMI 输入口：接电脑显卡的 HDMI 输出（看画面）
- USB 口：接电脑（未来控制鼠标用，本阶段未使用）
- 网口：连接网络（Web 控制台用）

## 四、怎么开机使用？

1. 盒子接电源、HDMI 线、网线
2. 盒子自动启动 AI 核心（systemd 服务 `ttbox-core.service`）
3. 电脑打开浏览器访问 Web 控制台（板端 IP:8080）
4. Web 页面可以看到：实时状态、检测结果、配置参数

## 五、当前能做什么？（第13阶段）

- ✅ 电脑画面 → HDMI → 盒子 → AI 检测（真实有效）
- ✅ 检测到目标：类别（人/车/公交）、置信度、位置框
- ✅ 目标选择：多个目标选一个
- ✅ 坐标换算：目标位置 → 瞄准点
- ✅ 控制器：算出鼠标命令（MouseCommand）
- ⛔ **鼠标没有真正动**（安全开关保持关闭）

## 六、安全红线（永远不变）

| 开关 | 状态 | 含义 |
|---|---|---|
| output_enabled | **false** | 输出后端关闭 |
| injection_allowed | **false** | 注入不允许 |
| mouse_dx/dy | **0** | 没有鼠标移动 |

**为什么？** 鼠标注入是"真的动你鼠标"的外部副作用，
必须等控制逻辑全部验证无误后才考虑。当前阶段只算命令、不执行命令。

## 七、怎么知道盒子在正常工作？

### 方法1：看系统状态

```bash
systemctl status ttbox-core.service
# 看到 active (running) = 正常运行
```

### 方法2：看实时指标

```bash
/opt/ttbox/core/build/ipc_ping --type GET_STATUS
```

看这几个关键字段：
- `capture_fps` ≈ 140（采集正常）
- `fps` ≈ 39~43（AI 推理正常）
- `detect_count` = 5（检测到目标；0 = 画面里没有模型认识的东西，正常）
- `injection_allowed` = false（安全）
- `mouse_dx/mouse_dy` = 0（没动鼠标）

### 方法3：看链路诊断（pipeline_debug）

config 开启 `pipeline_debug_enabled` 后，日志里每 60 帧输出一次：

```
[PIPELINE] frame=2486 size=2560x1440
  Detector: detections=5
  Target: valid=1 class=5 conf=0.880
  TargetPoint: valid=1 x=1236.9 y=733.3
  Controller: error=(-43.1,13.3) dx=0 dy=0
  Mouse: DISABLED
```

一行就能看出哪一层有问题：检测数、选中的目标、瞄准点、误差、命令。

## 八、常见疑问

### 为什么检测到 0 个目标？
模型只认识训练过的类别（COCO 80 类：人/车/公交/猫/狗...）。
桌面图标、纯色画面、陌生物体 → 检测不到，这是**正常的**（不是坏了）。

### 为什么画面里有人却检测不到？
- 人太小/太模糊 → 置信度低于阈值被过滤
- 模型是 COCO 通用模型，不是专用模型

### 为什么鼠标不动？
**这是设计如此。** 本阶段 `output_enabled=false`，只算命令不执行。
等下一阶段验证完控制逻辑，才会（在明确授权下）开启。

## 九、日常操作

| 操作 | 命令 |
|---|---|
| 查看服务状态 | `systemctl status ttbox-core.service` |
| 重启服务 | `systemctl restart ttbox-core.service` |
| 查看日志 | `journalctl -u ttbox-core.service -n 50 --no-pager` |
| 切换模型 | 改 config 的 model_path + 重启 |
