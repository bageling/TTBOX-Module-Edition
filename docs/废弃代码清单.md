# 废弃代码清单

本文列出仓库里**不再接入运行链路**、或**已经被新实现取代**的代码和脚本，方便新人避开，也方便以后清理。

判断标准：

1. 没有被 `CMakeLists.txt` 引用。
2. 没有被 systemd 服务引用。
3. 没有被网页后端引用。
4. 已有同名/同职责的新实现。

## 四、以后怎么避免再产生废弃代码

1. 新脚本放 `core/tools/` 或 `core/tests/`，不要在仓库根目录乱放。
2. 新增 C++ 测试必须写进 `core/CMakeLists.txt`，否则不会被 `ctest` 执行。
3. 板端 `.bak*` 文件不要拷回仓库。
4. 改完文档后，更新 `README.md` 和 [docs/README.md](README.md) 的导航，保证小白能找到入口。
