# 真实 HDMI 闭环验证（2026-09-03）

```

  ↓ GameViewer 虚拟显示
  ↓ 显卡 HDMI 输出

  ↓ RKNN NPU（3 核并行，43.1 FPS）
  ↓ DecodeNMS（解码 + NMS + 坐标映射回原图）
Detection 检测结果
```
