## 一、核心控制链路（唯一实际产出）确认

AimThread.cpp:169-170 是鼠标移动的唯一产出点：

```cpp
aibox_x = static_cast<float>(pid_x_.update(control_x));  // X= Pid1Controller
aibox_y = static_cast<float>(pid_y_.update(control_y));  // Y= Pid1Controller
```

- `pid_x_/pid_y_` 类型 = **Pid1Controller.hpp**（= 你给的 pid1.cpp 移植，逐行一致）。
- `MotionController`（A10，含 ki/kd 积分、clamp ±127）在 AimThread 里**只有 `.reset()`，从不 `.update()`** → 是**死代码**，从不产生输出。

## 五、重要结论（给后续改代码的人）

1. **PID 算法唯一标准 = `Pid1Controller.hpp`（= 用户 pid1.cpp）**，改动只在这一处。
2. `MotionController.hpp`（A10，ki/kd+clamp127）、`Deadzone.hpp`、`Smooth.hpp` 均为**保留但未接入**的备用代码，不要依赖它们的结果。
3. 三者插件的字段（pull_curve/continuous_lead/humanize）前端可配但后端无消费，**标注死参数，不删除数据结构**。
4. 目标是让用户只在「有效参数」上做调节，死参数在 UI 上置灰/加「未接线」标签。
