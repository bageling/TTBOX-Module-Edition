# 完整数据链路

> 本文档描述一帧画面从电脑屏幕出发，走完整个系统，最终变成 MouseCommand 的完整旅程。
> 特别注意：**本阶段在 MouseCommand 停止**，不写任何鼠标设备。

## 一、完整链路图（中文）

```
PC 游戏/桌面画面
  ↓
GameViewer 虚拟显示（EDID 虚拟显示器）
  ↓
显卡 HDMI 输出
  ↓ ═══════════ HDMI 线（只传画面）═══════════
RK3588 HDMI RX（hdmirx 硬件接收）
  ↓
rk_hdmirx（内核驱动）
  ↓
/dev/video0（V4L2 视频设备 = "画面水龙头"）
  ↓
Capture（采集线程，140+ FPS 抓帧）
  ↓
Frame（一帧画面数据）
  ↓
RGA（硬件图像处理：中心裁剪 500×500 → 缩放 640×640）
  ↓
Detector（AI 检测器）
  ↓
RKNN / NPU（神经网络推理，yolo261n 模型）
  ↓
DecodeNMS（解码：数字 → 检测框，坐标映射回原图）
  ↓
Detection[]（检测结果列表）
  ↓
TargetSelector（目标选择器：从多个目标选一个）
  ↓
Target（选中的目标）
  ↓
Coordinate（坐标转换：目标框 → 瞄准点）
  ↓
TargetPoint（控制目标点）
  ↓
Controller / PID（控制器：误差 → PID → 鼠标命令）
  ↓
MouseCommand（鼠标命令 dx/dy）
  ↓
【本阶段停止】════════════════════════════
  ↓
Mouse / HID（未来：写 /dev/hidg*，本阶段禁止）
```

## 二、两条线路（必须分清）

```
┌───────────── 视频链路（HDMI）─────────────┐
│  电脑画面 → 盒子（盒子"看"电脑）            │
│  = 盒子的"眼睛"                            │
└───────────────────────────────────────────┘

┌───────────── 控制链路（USB）──────────────┐
│  盒子 → 电脑（盒子"操作"电脑，如鼠标）      │
│  = 盒子的"手"（本阶段未使用）               │
└───────────────────────────────────────────┘
```

**重要概念**：
- **USB 不是视频链路**。USB 是盒子与电脑之间的**独立通信/设备连接**（伪装鼠标键盘）。
- **RK3588 没有物理显示器**。盒子的"画面"全部来自 HDMI 输入，盒子自己不带屏幕。

## 三、数据在每个环节的样子

| 环节 | 数据结构 | 内容 |
|---|---|---|
| Capture | Frame（FrameBuffer） | 像素数据 + 宽高/格式/帧号/时间戳 |
| RGA 后 | PreprocessedFrame | 模型输入尺寸图像（640×640） |
| NPU 输出 | raw_outputs | 模型原始数字输出（[1,84,8400]） |
| DecodeNMS 后 | Detection[] | 类别/置信度/坐标（原图坐标） |
| TargetSelector | Target | 选中的目标（class/conf/box/center/id） |
| Coordinate | TargetPoint | 控制目标点（x/y） |
| Controller | MouseCommand | 鼠标命令（dx/dy/valid） |

## 四、坐标系变换（关键！）

```
模型坐标系（640×640，NPU 看到的小图）
    ↓ DecodeNMS 内部映射（含 ROI→原图）
原图坐标系（2560×1440，Detection 的坐标）
    ↓ Coordinate 计算瞄准点（框内 offset）
瞄准点（原图坐标，TargetPoint）
    ↓ Controller 计算误差（目标点 - 参考点）
误差（像素，参考点 = 屏幕中心 + aim_offset）
    ↓ PID + 输出链
MouseCommand（dx/dy）
```

**核心事实**：DecodeNMS 输出的 Detection 坐标**已经是原图坐标**（已含 ROI→原图映射），
TargetSelector / Coordinate / Controller 全部在原图坐标系工作，无需二次换算。

## 五、真实链路数据（第13阶段实测）

```
[PIPELINE] frame=2486 size=2560x1440
  Detector: detections=5
  Target: valid=1 class=5 conf=0.880 id=1 center=(1238.6,745.0)
  Box: x1=1196.5 y1=706.1 x2=1280.7 y2=783.9
  TargetPoint: valid=1 x=1236.9 y=733.3
  Controller: error=(-43.1,13.3) dx=0 dy=0 valid=1
  Mouse: DISABLED
```

含义：AI 从真实 HDMI 画面检测到 5 个目标，选中公交车（class=5），
算出瞄准点 (1236.9, 733.3)，误差 (-43.1, 13.3)，
输出 MouseCommand dx=0 dy=0（**因为注入关闭，Mouse=DISABLED**）。
