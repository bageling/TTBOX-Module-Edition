# 系统总览（TTBOX-模块版）

## TTBOX 是什么？

TTBOX 是一台 **基于 RK3588 芯片的 AI 视觉盒子**。

它做什么？一句话：
> **盒子通过 HDMI 线"看"电脑屏幕，用 AI 识别画面里的目标，然后（可选）控制鼠标。**

整个系统跑在一块小小的 ARM 开发板上（OrangePi 5 Plus，RK3588），
电脑的画面通过 HDMI 线送进盒子，盒子里的 AI 每秒钟分析几十帧画面，
告诉上层"画面里有什么、目标在哪"。

## 它解决什么问题？

传统外挂/工具只能通过游戏内部接口获取数据（容易被检测）。
TTBOX 走的是"外部视觉"路线：
- **不读内存**，不看游戏数据
- **只"看"屏幕**（和人类一样通过 HDMI 看画面）
- AI 从画面中识别目标（完全基于图像）

## 运行在哪里？

| 组件 | 位置 |
|---|---|
| AI 盒子（RK3588） | OrangePi 5 Plus 开发板 |
| 操作系统 | Armbian Linux（内核 5.10/6.1 rockchip） |
| AI 核心（C++） | `/opt/ttbox/core`（systemd 托管） |
| Web 控制台（Python） | `/opt/ttbox/scripts/ttbox_web.py` |
| 模型 | `/opt/ttbox/models`（.rknn 格式） |

## 硬件是什么？

```
┌─────────────── 电脑（Windows PC）───────────────┐
│ 主屏幕 2560×1440                                  │
│   ↓ GameViewer 虚拟显示器（EDID）                  │
│   ↓ 显卡 HDMI 输出                                 │
└────────────────────┬────────────────────────────┘
                     │ HDMI 线（传画面）
┌────────────────────▼────────────────────────────┐
│            RK3588 AI 盒子（OrangePi 5 Plus）       │
│  HDMI RX (rk_hdmirx) → /dev/video0               │
│  → V4L2 采集 → RGA 图像处理 → RKNN NPU 推理        │
│  → DecodeNMS 解码 → 目标选择 → 坐标 → 控制          │
│  Web 控制台（浏览器访问）                          │
└──────────────────────────────────────────────────┘
```

## 系统分层（从上到下）

```
┌─────────────────────────────────────────┐
│  Web 控制层   浏览器页面 ↔ Web 服务 ↔ IPC  │
├─────────────────────────────────────────┤
│  功能插件层   web/preview/model/fan/wifi │
│              /network/monitor/log/...   │
├─────────────────────────────────────────┤
│  控制输出层   目标选择 → 坐标 → PID → HID  │
├─────────────────────────────────────────┤
│  AI 检测层   RGA → RKNN NPU → DecodeNMS │
├─────────────────────────────────────────┤
│  采集层      V4L2 采集 /dev/video0       │
├─────────────────────────────────────────┤
│  硬件层      RK3588 + HDMI RX + NPU      │
└─────────────────────────────────────────┘
```

## 两条关键线路（必须分清）

### 1. 视频链路（HDMI）—— 盒子的"眼睛"
```
电脑画面 → HDMI → 盒子（盒子"看"电脑）
```
### 2. 控制链路（USB）—— 盒子的"手"
```
盒子 → USB → 电脑（盒子"操作"电脑，如鼠标）
```
**USB 不是视频链路！**
USB 是盒子与电脑之间的独立通信/设备连接（伪装成鼠标键盘）。
HDMI 负责看，USB 负责操作，两条线各干各的。
