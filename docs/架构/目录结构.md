# 目录结构

## TTBOX-模块版 顶层目录

```
TTBOX-Module-Edition/
├── README.md              # 项目说明（第一眼就看这个）
├── LICENSE                # 开源协议
├── .gitignore             # Git 忽略规则
├── pyproject.toml         # Python 项目定义
│
├── core/                  # ★ C++ 核心（AI 高速链路，最重要的代码）
│   ├── CMakeLists.txt         # 构建脚本
│   ├── src/                   # 源码（capture/rga/rknn/model/mouse/aim/output/hid/...）
│   ├── tools/                 # 工具程序（imgdetect/ipc_ping/HID 工具）
│   ├── tests/                 # C++ 测试
│   └── include/               # 公共头文件
│
├── framework/             # Python 框架层（插件管理/配置/服务/安全）
│   ├── plugin_manager/        # 插件管理
│   ├── config/  service/  security/
│   └── tests/
│
├── plugins/               # 功能插件（12 个）
│   ├── web/  preview/  model/
│   ├── fan/  wifi/  network/  monitor/
│   ├── log/  system/  upgrade/
│   └── system_common.py  system_host.py
│
├── platform/              # 平台层（板端运维：systemd/运行时/模型/健康）
│   ├── supervisor/  runtime/  model/  health/  config/  update/
│   └── tests/
│
├── modules/               # ★ 模块化语义视图（小白从这里看结构）
│   ├── README.md              # 模块总览
│   ├── 01-capture/            # 采集层
│   ├── 02-image/              # 图像处理层
│   ├── 03-detector/           # AI 模型层
│   ├── 04-decoder/            # 检测解码层
│   ├── 05-selector/           # 目标选择层
│   ├── 06-coordinate/         # 坐标层
│   ├── 07-controller/         # 控制层
│   ├── 08-mouse/              # 鼠标输出层
│   └── 09-runtime/            # 运行时层
│
├── models/                # 模型（本机安全样本；真实模型在板端）
├── config/                # 配置文件（default.json 等）
├── scripts/               # 运维脚本 + Web 主程序（ttbox_web.py）
├── ttbox_motion/          # 运动控制（校准/训练）
├── tests/                 # 集成测试（可选）
├── packages/              # 打包产物（可选）
└── docs/                  # ★ 文档中心
    ├── 整理前代码现状.md       # 整理前的真实快照
    ├── 架构/                  # 系统总览/完整链路/核心模块/插件系统/数据流/目录结构
    ├── AI/                    # 模型系统/模型输入格式
    ├── 验证/                  # 真实HDMI闭环验证
    ├── 小白教程/              # 01-10 入门教程
    ├── 开发/                  # 修改指南
    ├── 规划/                  # 项目路线图
    └── (历史文档)              # 保留的原始文档
```

## core/src 内部结构（真实源码位置）

```
core/src/
├── capture/    # 视频采集（V4L2 + DMA-BUF）
├── rga/        # RGA 图像处理
├── rknn/       # RKNN 推理 + 预处理 + 解码（Preprocess/RKNNEngine/DecodeNMS/WorkerPool）
├── model/      # 模型适配与注册（ModelAdapter/ModelRegistry/RuntimeProfile）
├── detector/   # 检测器接口 + 高性能引擎
├── mouse/      # 目标选择 + 坐标 + 运动（TargetSelector/CoordinateTransform）
├── aim/        # 瞄准线程 + PID
├── output/     # 鼠标输出后端
├── hid/        # HID 转发与解析
├── input/      # 物理鼠标读取
├── pipeline/   # 目标数据信箱
├── preview/    # 预览模块
├── ipc/        # IPC 服务
├── runtime/    # 运行时组装
├── app/        # 应用主类
├── config/     # 配置管理
├── common/     # 公共工具
├── auth/       # 授权校验
├── bench/      # 性能基准
└── main.cpp    # 程序入口
```

## 重要说明：modules/ 与 core/src/ 的关系

- **modules/** = 语义视图：按数据流顺序（01-09）讲清楚系统结构，适合学习和讲解
- **core/src/** = 真实源码：CMake 编译实际引用的位置，代码真正在这里

两者通过 `modules/*/README.md` 里的"关键文件"表格一一对应。
**不物理移动源码**，避免破坏已经验证成功的构建和运行。
