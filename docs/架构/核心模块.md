# 核心模块

本文档逐个介绍 TTBOX 的核心概念与模块，每个都回答：
**它是什么？干什么？输入？输出？谁调用？不能干什么？改它影响什么？**

---

## 1. Capture（采集）

- **是什么**：从 /dev/video0 抓取 HDMI 画面的线程
- **干什么**：打开 V4L2 设备，循环取帧，维护最新帧缓存
- **输入**：/dev/video0（BGR3 2560×1440）
- **输出**：FrameBuffer（原始画面帧）
- **谁调用**：CoreRuntime；Worker 通过 LatestFrame 拿帧
- **不能干什么**：不做图像处理、不推理
- **改动影响**：帧率、画面格式、所有下游

## 2. Frame（帧）

- **是什么**：一帧画面的数据结构
- **干什么**：承载像素数据 + 元信息（宽高/格式/帧号/时间戳/DMA fd）
- **输入**：V4L2 缓冲区
- **输出**：给 RGA/预处理用
- **注意**：DMA-BUF 实现零拷贝，避免不必要的内存复制

## 3. RGA（图像处理硬件加速）

- **是什么**：RK3588 自带的 2D 图像加速器
- **干什么**：裁剪（ROI 500×500）、缩放（到模型尺寸）、格式转换
- **输入**：原始帧 + 裁剪配置
- **输出**：模型输入尺寸的图像
- **改动影响**：性能与喂给 AI 的画面

## 4. Detector（检测器）

- **是什么**：AI 推理的统一入口
- **干什么**：加载模型 → 预处理 → NPU 推理 → 解码
- **输入**：PreprocessedFrame
- **输出**：Detection 列表
- **相关**：RKNNEngine（底层）、WorkerPool（多 Worker 并行）

## 5. Detection（检测结果）

- **是什么**：一个"画面里有目标"的结论
- **字段**：class_id（类别编号）、score（置信度）、x1/y1/x2/y2（原图坐标）
- **例子**：`class=2 score=0.90 box=[1305,746,1383,801]`（一辆车）

## 6. Decoder（解码器）

- **是什么**：把模型原始输出翻译成检测框
- **干什么**：解码坐标 → 过滤低置信度 → NMS 去重 → 映射回原图坐标
- **相关**：DecodeNMS、ModelAdapter（自动识别模型格式）

## 7. TargetSelector（目标选择器）

- **是什么**：从多个目标中挑一个
- **干什么**：按"离中心最近"或"指定类别"选择，多帧稳定防跳变
- **输入**：Detection 列表
- **输出**：选中目标

## 8. CoordinateTransform（坐标变换）

- **是什么**：目标位置 → 屏幕中心偏差
- **干什么**：计算 error_x/error_y（目标偏离中心多少像素）
- **输入**：目标位置 + 屏幕中心
- **输出**：偏差量

## 9. MouseCommand（鼠标指令）

- **是什么**：控制层输出的"该动多少"的指令
- **字段**：dx、dy（移动量）
- **生成者**：AimThread + PID
- **执行者**：OutputBackend → HID（当前关闭）

## 10. Plugin（插件）

- **是什么**：可插拔的功能单元（web/preview/model/fan/wifi/...）
- **结构**：plugin.json（声明）+ plugin_entry.py（入口）
- **管理**：framework/plugin_manager/（发现/安装/生命周期/完整性）
- **作用**：让系统功能按需加载，不用的功能不占资源

## 11. RuntimeConfig（运行时配置）

- **是什么**：系统所有可调参数的统一配置
- **来源**：config/default.json（启动加载）+ IPC 热更新
- **内容**：模型路径、阈值、ROI、PID 参数、输出开关
- **注意**：`output_enabled` 是安全开关，默认 false

## 模块间关系总图

```
Capture → Frame → RGA → Preprocess → RKNNEngine → DecodeNMS
                                    ↓                ↓
                              Detection ◄── ModelAdapter
                                    ↓
                              TargetSelector → CoordinateTransform
                                    ↓
                              AimThread(PID) → MouseCommand → HID(关闭)
```

> 每个模块的详细说明见 `modules/` 目录（01-09 编号对应数据流顺序）。
