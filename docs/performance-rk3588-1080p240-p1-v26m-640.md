# P-1 640 模型测试报告：v26m（三角洲 640）ONNX→RKNN→C++ 链路（ttbox2）

> **阶段**：640 模型转换/验证/测试（未修改 A1-A6 语义、未进 A7-A10、无 Python 进链路）
> **日期**：2026-08-14
> **配置**：3 Worker 绑 A76(cpu4,5,6) / NPU core_mask{1,2,4} / 8 V4L2 buffers / conf=0.55 iou=0.45 / 全锁频
> **核心结论**：640 模型已成功接入 A1-A6 C++ 链路。**3W INT8 最高 29.9fps（240fps 利用率 12.5%），无法跑满 240fps**——瓶颈为 NPU 单帧推理（INT8 87.5ms / FP16 193ms），模型算力物理限制。e2e 输出使 Decode/NMS 开销几乎为 0（2µs），输入转换/CPU/DDR 均非瓶颈。

## 3. 对齐验证（ONNX reference vs RKNN）

- **颜色顺序判定**：模型期望 **RGB**（PIL/torch 系）。ONNX-RGB 与 RKNN-FP16-RGB 输出**完全一致**（真实图 calib_3：ONNX top1 (144.13,155.24)-(169.60,242.16) score=0.765 vs RKNN (144,155.25)-(169.63,242.13) score=0.761）。
- **归一化**：ONNX 输入需 /255（0-1），RKNN 由 runtime /255，一致。
- **转换正确性 PASS**：真实图检测框/分数逐位接近；随机噪声输入 MAE 大属 e2e TopK 选择对微小数值差异敏感，非转换错误（真实图验证为准）。

## 4. ModelAdapter 通用能力扩展（不改 single/DFL 语义）

本模型暴露两类现有描述缺失，已扩展通用能力：

1. **e2e 单输出解码**（DecodeNMS `process_e2e`）：单输出 3D `[1,N,F]` 且 `F<=16` → 端到端路径（conf 过滤 + classwise NMS，幂等）。分发条件通用（不看输出名/不写死模型），`[1,84,8400]` 传统格式仍走 process_single，`黄瓦` 仍走 process_dfl。
2. **颜色顺序通用化**（模型输入属性）：RgaProcessor `out_color`（BGR888/RGB888）+ WorkerPool/config `model_color_order`（默认 bgr 兼容既有模型）。v26m 需 rgb（RGA 输出时硬件 BGR→RGB）。

## 6. 重点分析（10 项回答）

| 问题 | 答案 |
|---|---|
| 1. 640 模型 NPU 单帧耗时 | **FP16 193ms / INT8 87.5ms**（1GHz 单核） |
| 2. 3 Worker 能否有效利用三核 | **能**（IRQ 三核均衡），但每核 run 退化：FP16 193→226ms（+17%）、INT8 87.5→94ms（+7%）；吞吐线性度 INT8 更好 |
| 3. RGA 是否新瓶颈 | **否**：2.0~2.5ms，占 INT8 total 2.5%（黄瓦同量级，无 640 附加开销） |
| 4. 输入转换是否瓶颈 | FP16 12.8ms（7%）；**INT8 0.17ms（0.2%），非瓶颈** |
| 5. Decode 是否因 640 输出规模增加 | **否**：e2e 输出 [1,300,6] 仅 **1~2µs**（对比 yolo DFL 640 的 3ms，**e2e 格式解码开销降低 3 个数量级**） |
| 6. NMS 是否消耗 CPU | **~0**：模型已做 TopK 选择，候选极少，NMS 幂等无开销 |
| 7. CPU4/5/6 绑定是否仍有效 | 有效（零迁移），但 640 模型 run 主导，绑核收益被 NPU 耗时淹没（INT8 3W 吞吐 29.9 与不绑核持平） |
| 8. DDR 是否开始瓶颈 | **未饱和**：峰值 57%（高于黄瓦 34%，640 权重搬运更重），平均 35%，余量 43% |
| 9. INT8 vs FP16 真实差距 | 吞吐 **2.3~2.5×**（3W 12.0→29.9）、run **2.2×**（193→87.5ms）、set_input **75×**（12.8→0.17ms） |
| 10. 240fps 能否跑满 | **不能**：最高 3W INT8 29.9fps（240 利用率 12.5%），差 210fps；3 核理想线性也仅 ~33fps（87.5ms/核），**物理差距 ~7×** |

## 7. 240fps 达标情况与新瓶颈定位

- **未达到 240fps**。Capture 240fps 恒定，AI Pipeline 最高 29.9fps（3W INT8）。
- **最大瓶颈：NPU 单帧推理**（INT8 run 87.5ms）——640 分辨率大模型在 RK3588 1GHz 的算力物理极限。run 占 INT8 total 99%+。
- 其余全部非瓶颈：输入转换 0.17ms、RGA 2.4ms、Decode/NMS ~0、CPU 2%、DDR 峰值 57%、温度 71°C、poll 0。
- 如实报告：**640 模型（无论 FP16/INT8、1~3W）无法接近 240fps**，最佳为 3W INT8 29.9fps。
