## 🚀 下一阶段

### 目标：控制输出闭环（Detection → TargetSelector → Coordinate → 控制输出）

优先级顺序：

1. **Detection → TargetSelector 联调**
   - 多目标场景下的目标选择稳定性
   - 目标切换平滑（stable_frames 机制调优）

2. **Coordinate 精度验证**
   - 不同分辨率/ROI 下的坐标映射
   - 轴比例与 FOV 参数标定

3. **控制输出（逻辑验证，不开真实注入）**
   - AimThread + PID 逻辑全链路验证
   - 用模拟输出（TraceHidOutput）验证指令正确性

4. **Web 控制台完善**
   - 实时检测结果可视化（画框预览）
   - 参数在线调节

> ⚠ 全程保持 output_enabled=false、injection_allowed=false
> 本阶段只验证逻辑，不开启真实鼠标注入
