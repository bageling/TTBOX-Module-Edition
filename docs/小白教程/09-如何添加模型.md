# 09 - 如何添加模型？

## 前提条件

- 有一台 RK3588 的 TTBOX 盒子（板端）
- 有一个 `.rknn` 格式的模型文件
  （没有的话需要先训练模型 + 用 rknn-toolkit2 转换，见 docs/AI/模型系统.md）

## 完整步骤（5 步）

### 第一步：把模型放到板端

用 scp 或 Web 页面上传，放到：

```
/opt/ttbox/models/staging/我的模型/model.rknn
```

（staging = 暂存区，先放这里，验证没问题再正式安装）

### 第二步：修改配置

编辑 `/opt/ttbox/config/default.json`：

```json
{
  "model_path": "/opt/ttbox/models/我的模型/model.rknn",
  "model_input_width": 640,
  "model_input_height": 640,
  "conf": 0.30,
  "output_enabled": false
}
```

⚠ **三个必须匹配**：
1. `model_path` 指向你的模型文件（**必须显式指定**）
2. `model_input_width/height` = 模型的输入尺寸（不能猜！）
3. 输入格式符合模型要求（颜色序/归一化）

### 第三步：重启服务

```bash
systemctl restart ttbox-core.service
```

### 第四步：检查日志

```bash
journalctl -u ttbox-core.service -n 30 --no-pager | grep -E "rknn_init|模型信息"
```

看到类似就成功了：
```
rknn_init OK: /opt/ttbox/models/我的模型/model.rknn
模型信息: 输入 1 输出 1 | 输入 640x640 FLOAT16 NHWC
```

### 第五步：验证检测

用状态接口看检测是否工作：

```bash
/opt/ttbox/core/build/ipc_ping --type GET_STATUS
```

检查 `detect_count` 是否大于 0、`detection_boxes` 是否有内容。

## 常见错误

| 错误现象 | 原因 | 解决 |
|---|---|---|
| 日志显示加载了旧模型 | model_path 没改/没生效 | 显式设置 model_path |
| 模型加载失败 | 路径错/格式错 | 检查文件路径和 .rknn 格式 |
| 加载成功但检测为 0 | 输入格式不对 | 看 docs/AI/模型输入格式.md |
| 输入尺寸不匹配 | config 尺寸 ≠ 模型尺寸 | 查询模型元数据（用探针工具）|

## 怎么知道模型的输入尺寸/类型？

用模型探针工具（板端）：

```bash
# 编译好的探针（core/tools/yolo_probe.c）
/tmp/yolo_probe 模型.rknn 测试帧.raw 2560 1440
```

输出会显示：`model in=640x640 type=1(F16) fmt=NHWC` 等元数据。

## 模型添加完成后的检查清单

- [ ] 模型文件在板端（路径正确）
- [ ] config 的 model_path 指向它
- [ ] 输入尺寸匹配
- [ ] 服务重启成功
- [ ] 日志显示模型加载 OK
- [ ] GET_STATUS 显示 detect_count > 0
- [ ] 检测框坐标与画面目标位置一致
- [ ] output_enabled 保持 false（安全）
