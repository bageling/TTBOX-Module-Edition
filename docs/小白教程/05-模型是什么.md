# 05 - 模型是什么？

## 一句话

模型 = 一个装满了"知识"的文件（`.rknn` 格式），
是 AI 的"大脑"。没有模型，AI 什么都不会。

## 打个比方

模型就像一本"看图识物"的字典：
- 字典里写着"什么样子的图形 = 汽车"
- AI 推理时翻开字典，对照画面，认出"这是汽车"

这本字典是**训练**出来的：
让模型看几百万张标注好的图片，不断调整内部数字（权重），
直到它学会"看见汽车的样子就输出'汽车'"。

## TTBOX 的模型长什么样？

```
文件：yolo261n-rk3588.rknn（8.3 MB）
位置：板端 /opt/ttbox/models/
格式：RKNN（瑞芯微专用格式，只能在 RK 芯片上跑）
```

一个模型由这几部分决定：

| 属性 | 含义 | yolo261n 的值 |
|---|---|---|
| 输入尺寸 | 模型看多大的图 | 640×640 |
| 数据类型 | 数字怎么存（精度） | FP16 |
| 输出结构 | 结果长什么样 | [1,84,8400] |
| 类别数 | 能识别几种物体 | 80 类（COCO） |

## 模型从哪来？

1. **训练**：用大量图片+标注训练一个神经网络（如 YOLO 系列）
2. **转换**：把训练好的模型转成 RKNN 格式（用 rknn-toolkit2）
3. **部署**：把 .rknn 文件放到板端 /opt/ttbox/models/
4. **配置**：修改 config/default.json 的 model_path 指向它
5. **重启**：重启 ttbox-core 服务加载新模型

## TTBOX 现有的模型

| 模型 | 能识别什么 | 速度 | 适用 |
|---|---|---|---|
| yolo261n | 80 种常见物体（人/车/公交/猫/狗...） | 43 FPS | 通用场景 |
| jwdl_sjzv11 | 7 种特定游戏角色 | 142 FPS | 游戏专用 |
| sjz 系列 | 游戏角色变体 | ~140 FPS | 游戏专用 |

**选择原则**：
- 要通用 → yolo261n
- 要最快 → jwdl
- 游戏特定 → sjz 系列

## 为什么模型大小/输入尺寸影响速度？

- 输入越大（640 vs 256）→ 计算量越大 → 越慢
- 类别越多 → 判断越复杂 → 越慢
- yolo261n 输入是 jwdl 的 2.5 倍宽 → 计算量约 6 倍 → 慢 8.6 倍

## 换个模型需要注意什么？

⚠ **三个必须匹配**：
1. `model_path` 指向正确的模型文件
2. `model_input_width/height` = 模型的输入尺寸
3. 输入格式（颜色序/归一化）符合模型要求

任何一个不对，模型就可能"失明"（加载成功但检不出东西）。
详见 `docs/AI/模型输入格式.md` 的教训。
