# 04 - AI 是怎么识别目标的？

## 先记住一个名字：NPU

NPU = Neural Processing Unit，**专门负责人工智能计算的处理器**。

普通 CPU 也能算 AI，但太慢（一帧要好几百毫秒）。
NPU 是专门为神经网络设计的芯片，又快又省电：
RK3588 的 NPU 算一帧 640×640 只要 63 毫秒。

## AI 识别目标的三步

```
第一步：准备图片（预处理）
  大画面 → 裁剪出中间 500×500 → 缩放到 640×640
  就像把一张大海报裁出中间一块，缩小成小卡片

第二步：神经网络计算（推理）
  小卡片图片 → NPU 里的模型 → 输出一堆数字
  模型"看"图的方式：一层一层找特征
  （先找边缘 → 再找形状 → 再认出"这是辆车"）

第三步：翻译结果（解码）
  一堆数字 → 检测框（类别 + 置信度 + 位置）
  人终于能看懂了！
```

## 模型在 NPU 里做了什么？

可以把模型想象成一个"超级分类器"，它被训练过"看了几百万张图"，
学会了"什么样的像素组合是汽车、什么是人、什么是公交车"。

推理时：
1. 模型把 640×640 图片切成很多小格子（8400 个候选位置）
2. 每个格子判断：这里有没有目标？是什么？有多大？
3. 输出 8400 个"候选框"，每个包含：位置 + 类别分数

## 从 8400 个候选到几个检测框（解码）

模型一次性输出 8400 个候选框，其中绝大多数是"没目标"或"重复的"。

```
8400 个候选框
   ↓ 过滤：置信度低于 0.30 的扔掉
 几百个"像目标"的
   ↓ NMS 去重：重叠的框只留最好的
  5 个最终检测框（实测）
```

NMS = Non-Maximum Suppression（**非极大值抑制**）：
多个重叠框 → 只保留得分最高的那个。
比如一辆车被框了 8 次，NMS 后只留 1 个框。

## 实测的识别结果

TTBOX 在真实街景画面上识别到（2026-09-03 实测）：

```
[类别=人(person)    置信度=0.83  位置=(1502,706)-(1529,969)]
[类别=汽车(car)     置信度=0.90  位置=(1305,746)-(1383,801)]
[类别=汽车(car)     置信度=0.86  位置=(1357,742)-(1411,777)]
[类别=汽车(car)     置信度=0.80  位置=(1443,735)-(1519,806)]
[类别=公交车(bus)   置信度=0.88  位置=(1196,706)-(1280,783)]
```

- **类别**：模型认出"这是什么"
- **置信度**：模型多确定（0~1，越高越有把握）
- **位置**：目标在画面的哪一块（原图像素坐标）

## 为什么有时候检测不到？

| 情况 | 原因 |
|---|---|
| 画面上没有模型认识的物体 | 正常！模型只认识训练过的类别 |
| 目标太小/太模糊 | 特征不明显，置信度低被过滤 |
| 模型输入格式不对 | 模型"失明"（见 docs/AI/模型输入格式.md）|
| 置信度阈值太高 | 设 conf 太高把真目标也过滤了 |
