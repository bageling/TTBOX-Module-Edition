# 06 - 检测框是什么？

## 一句话

检测框 = AI 在画面上用"方框"标出目标的位置，同时告诉你是"什么"、"多确定"。

## 一个检测框包含什么？

```
┌─────────────────────────────────────┐
│  person 0.83                        │  ← 类别标签 + 置信度
│  ┌───────────────────────────────┐  │
│  │                               │  │  ← 框住目标
│  │              🚶               │  │
│  │                               │  │
│  └───────────────────────────────┘  │
│  (x1,y1) = 左上角坐标                │
│  (x2,y2) = 右下角坐标                │
└─────────────────────────────────────┘
```

每个检测框（Detection）有 4 个关键信息：

| 字段 | 含义 | 例子 |
|---|---|---|
| class_id | 类别编号 | 0=人, 2=汽车, 5=公交车 |
| score | 置信度（0~1） | 0.90（很有把握） |
| x1, y1 | 框左上角坐标（原图像素） | 1305, 746 |
| x2, y2 | 框右下角坐标（原图像素） | 1383, 801 |

## 坐标是什么意思？

TTBOX 的画面是 2560×1440 像素：
- x 从左到右：0 ~ 2560
- y 从上到下：0 ~ 1440
- (0,0) 在左上角

检测框坐标就是**原图坐标**：
`box=[1305,746,1383,801]` 表示
从 (1305,746) 到 (1383,801) 这个矩形区域里有一个目标。

## 实测例子

在真实街景画面里，AI 检测到（2026-09-03 实测）：

```
[类别=人(person)  置信度=0.83  框=(1502,706)-(1529,969)]
[类别=汽车(car)   置信度=0.90  框=(1305,746)-(1383,801)]
[类别=汽车(car)   置信度=0.86  框=(1357,742)-(1411,777)]
[类别=汽车(car)   置信度=0.80  框=(1443,735)-(1519,806)]
[类别=公交车(bus) 置信度=0.88  框=(1196,706)-(1280,783)]
```

验证过：这些框的位置和画面里真实的车/人/公交车**对得上**（框内确有物体轮廓）。

## 检测框怎么产生的？

```
模型输出 8400 个候选框（很多是垃圾）
   ↓ 过滤低置信度（conf 阈值）
   ↓ NMS 去重（重叠只留最好的）
   ↓ 坐标映射（模型小图坐标 → 原图坐标）
5 个干净的检测框
```

## 检测框有什么用？

检测框是下游一切的基础：
1. **目标选择**：多个框 → 选一个要跟踪的
2. **坐标计算**：框的中心 → 与屏幕中心的偏差
3. **控制输出**：偏差 → 鼠标移动指令

## 常见问题

| 现象 | 原因 |
|---|---|
| 框太多 | conf 阈值太低 / NMS 没生效 |
| 框太少 | conf 阈值太高 / 目标太小 |
| 框的位置不对 | 坐标映射错误（已验证没问题） |
| 没框 | 画面没有模型认识的目标 / 输入格式错 |
