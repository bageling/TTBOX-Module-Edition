# 模块说明

> 本文档用中文解释每个模块：**它是什么 / 它干什么 / 它不干什么 / 输入是什么 / 输出是什么 / 谁调用它 / 它调用谁 / 以后怎么替换**。

## 模块总览（按数据流顺序）

| 模块 | 中文名 | 一句话 |
|---|---|---|
| Capture | 采集器 | 从 /dev/video0 抓画面帧 |
| Detector | 检测器 | AI 推理 + 解码，输出检测框 |
| TargetSelector | 目标选择器 | 从多个目标选一个 |
| Coordinate | 坐标转换 | 目标框 → 瞄准点 |
| Controller | 控制器 | 瞄准点 → 鼠标命令 |
| Mouse | 鼠标输出 | 写 HID 设备（本阶段未启用） |

---

## 1. Capture（采集器）

- **它是什么**：负责从 HDMI 画面源抓取帧的模块
- **它干什么**：打开 /dev/video0（V4L2 设备），循环取帧，维护"最新帧缓存"
- **它不干什么**：不做图像处理、不推理、不选择目标
- **输入**：/dev/video0（BGR3 格式，2560×1440）
- **输出**：Frame（一帧画面：像素 + 元信息）
- **谁调用它**：CoreRuntime（核心运行时）启动时调用
- **它调用谁**：V4L2 驱动、LatestFrame（最新帧缓存）
- **以后怎么替换**：实现 ICapture 接口即可换采集源（USB 摄像头/网络流）

## 2. Detector（检测器）

- **它是什么**：负责"看懂画面"的 AI 模块
- **它干什么**：
  1. 加载模型（.rknn 文件）
  2. 预处理（RGA 裁剪缩放）
  3. NPU 推理（RKNN）
  4. 解码（DecodeNMS：数字 → 检测框）
- **它不干什么**：不选择目标、不算坐标、不控制鼠标
- **输入**：Frame（一帧画面）
- **输出**：Detection[]（检测框列表：类别/置信度/坐标）
- **谁调用它**：WorkerPool（推理 Worker 池）
- **它调用谁**：RKNNEngine（NPU）、RgaProcessor（图像加速）、DecodeNMS（解码）、ModelAdapter（模型适配）
- **以后怎么替换**：模型细节（RKNN/tensor/NPU）全在内部；换模型 = 换配置（model_path），上层零改动

## 3. TargetSelector（目标选择器）

- **它是什么**：负责"打哪个"的模块
- **它干什么**：从 Detection[] 中按规则选一个目标：
  - 优先级1：锁定目标延续（track_lock）
  - 优先级2：矩形匹配（rect_lock）
  - 优先级3：离中心最近（score）
  - 丢失宽限：目标短时消失不立即切换
- **它不干什么**：不检测（那是 Detector）、不算坐标、不控制鼠标
- **输入**：Detection[] + 配置（置信度阈值/类别过滤/FOV 范围）
- **输出**：Target（选中的目标：类别/置信度/框/中心/id）
- **谁调用它**：AimThread（瞄准线程）每帧调用
- **它调用谁**：无（纯算法，不依赖任何设备）
- **以后怎么替换**：不依赖 RKNN/V4L2/RGA/Mouse/HID/Web，可独立测试、独立替换

## 4. Coordinate（坐标转换）

- **它是什么**：负责坐标系换算的模块
- **它干什么**：
  - 计算瞄准点（框内 offset）：目标框 → 目标点
  - 计算参考点（准星）：帧中心 + aim_offset
  - 计算误差：目标点 - 参考点
- **它不干什么**：不选择目标、不控制、不写设备
- **输入**：Target（目标框）+ AimPointProfile（瞄准点配置）+ 帧尺寸
- **输出**：TargetPoint（控制目标点）+ 误差（error_x/error_y）
- **谁调用它**：AimThread（瞄准线程）
- **它调用谁**：无（纯数学）
- **以后怎么替换**：坐标换算集中一处；改分辨率/ROI/缩放只动这里

## 5. Controller（控制器）

- **它是什么**：负责"算鼠标命令"的模块（本阶段核心新增）
- **它干什么**：
  - 误差计算：TargetPoint - 参考点
  - PID 控制：Pid1Controller（X/Y 双轴独立）
  - 输出链：PID × 灵敏度 × 缩放 → 死区 → 余数累积 → int16 截断
  - 安全防护：NaN/Inf 拒绝、越界 clamp、无目标清状态
- **它不干什么**：**绝不写 /dev/hidg\***、不知道 USB、不知道鼠标设备
- **输入**：TargetPoint（控制目标点）
- **输出**：MouseCommand（dx/dy/valid）
- **谁调用它**：AimThread（瞄准线程）
- **它调用谁**：Pid1Controller（PID 算法）
- **接口**：IController（统一接口）→ PidController（PID 实现）
- **以后怎么替换**：实现 IController 接口即可换算法（比例/滤波/预测/其他）

## 6. Mouse（鼠标输出，本阶段未启用）

- **它是什么**：负责"真正移动鼠标"的模块（未来）
- **它干什么**：把 MouseCommand 写入 HID 设备（/dev/hidg*）
- **它不干什么**：不算命令（那是 Controller）
- **输入**：MouseCommand（未来）
- **输出**：HID 报告（未来）
- **谁调用它**：OutputBackend（输出后端，本阶段未启用）
- **以后怎么实现**：实现 IHidOutput 接口；**当前 output_enabled=false 全程禁止**
