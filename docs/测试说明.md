# 测试说明

> 本文档说明 TTBOX-模块版怎么编译、怎么测试、测试了什么、真实结果是什么。

## 一、编译（开发机 Windows / 板端 RK3588）

### Windows（开发机）

```bash
# 配置
cmake -S core -B core/build -DCMAKE_BUILD_TYPE=Release

# 全量编译
cmake --build core/build --config Release

# 运行全部测试
ctest --test-dir core/build -C Release --output-on-failure
```

### 板端（RK3588）

```bash
cd /opt/ttbox/core/build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --target ttbox_core_main -j4
```

## 四、真实 HDMI 集成测试（第13阶段）

**目标**：证明真实 Detection 能进入完整 Pipeline（不是合成数据）。

**步骤**：
1. PC 全屏显示 COCO 街景图（2560×1440）→ HDMI → RK3588
2. 板端运行新版 ttbox_core（yolo261n 模型）
3. 开启 `pipeline_debug_enabled: true`（每 60 帧输出一次）
4. 查看 journalctl 确认完整链路输出

**真实结果**（journalctl 摘录）：

```
[PIPELINE] frame=2486 size=2560x1440
  Detector: detections=5
  Target: valid=1 class=5 conf=0.880 id=1 center=(1238.6,745.0)
  Box: x1=1196.5 y1=706.1 x2=1280.7 y2=783.9
  TargetPoint: valid=1 x=1236.9 y=733.3
  Controller: error=(-43.1,13.3) dx=0 dy=0 valid=1
  Mouse: DISABLED
```

**安全验证**（全程采样）：
- `output_enabled=false` ✅
- `injection_allowed=false` ✅
- `mouse_dx/mouse_dy = 0/0` ✅
- 检测数恒定 5 ✅

## 五、性能测试（pipeline_bench）

```bash
# 本机
cmake --build core/build --config Release --target pipeline_bench
core/build/Release/pipeline_bench.exe

# 板端
cd /opt/ttbox/core/build && g++ -std=c++17 -O2 -I../src -I../include \
  ../tests/pipeline_bench.cpp libttbox_core.a -o /tmp/pipeline_bench \
  -L/usr/local/lib -lrknnrt -lrga -ljpeg -lpthread && /tmp/pipeline_bench
```

**板端实测**（5000 帧均值）：TargetSelector 1.397us / Coordinate 0.131us /
Controller 0.563us / **Pipeline 总计 2.090us**（占 infer 0.003%）。
