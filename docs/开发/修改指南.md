## 通用规范（所有修改都必须遵守）

1. **先备份**：cp 文件 `.bak-$(date +%Y%m%d_%H%M%S)`
2. **最小修改**：只动要改的地方，不做无关重构
3. **跑测试**：改 C++ 跑 CTest；改 Python 跑 pytest
4. **板端回归**：真机验证基线（141 FPS 采集 / 检测正常）
5. **保持安全**：output_enabled=false、injection_allowed=false
6. **文档同步**：改完更新相关文档
